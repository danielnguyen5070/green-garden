# Bắt đầu với next-intl

`next-intl` giúp bạn dễ dàng triển khai các route theo locale như `/en` và `/vi` trên App Router.

## Vì sao dùng next-intl?

Thư viện hỗ trợ:

- định tuyến có tiền tố locale
- file messages cho bản dịch
- helper điều hướng dùng chung cho `Link` và `useRouter`

## Ví dụ

```ts
import {useTranslations} from 'next-intl';

export function Hero() {
  const t = useTranslations('home.hero');
  return <h1>{t('titleLine1')}</h1>;
}
```

> Giữ copy giao diện trong file messages, còn dữ liệu nghiệp vụ nên giữ trung lập về ngôn ngữ khi có thể.

Với cấu trúc messages rõ ràng, cùng một bộ component có thể phục vụ mọi locale mà không cần nhân đôi trang.
