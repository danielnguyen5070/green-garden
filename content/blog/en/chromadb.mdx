# ChromaDB for local RAG experiments

ChromaDB is a lightweight **embedding database** that works well for prototypes and local RAG workflows.

## Core idea

You store documents as vectors, then query by similarity instead of exact keywords.

```ts
const results = await collection.query({
  queryTexts: ["low light indoor plants"],
  nResults: 3,
});
```

## When it shines

- quick local experiments
- small knowledge bases
- early-stage semantic search

> Start simple with ChromaDB, then graduate to a managed vector store when traffic and scale demand it.
