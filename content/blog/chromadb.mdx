# ChromaDB cho thử nghiệm RAG tại máy local

ChromaDB là **cơ sở dữ liệu embedding** nhẹ, phù hợp cho prototype và quy trình RAG chạy local.

## Ý tưởng cốt lõi

Bạn lưu tài liệu dưới dạng vector, rồi truy vấn theo độ tương đồng thay vì khớp từ khóa chính xác.

```ts
const results = await collection.query({
  queryTexts: ["cây nội thất ưa bóng"],
  nResults: 3,
});
```

## Khi nào nên dùng

- thử nghiệm nhanh trên máy local
- kho tri thức nhỏ
- tìm kiếm ngữ nghĩa giai đoạn đầu

> Hãy bắt đầu đơn giản với ChromaDB, rồi chuyển sang vector store quản trị khi lưu lượng và quy mô tăng lên.
