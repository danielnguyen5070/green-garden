# What is Weaviate?

Weaviate is a **vector database**.

## Why use Weaviate?

It can store embeddings and perform semantic search.

```ts
const result = await collection.query.nearText("Next.js");
```

> Weaviate is useful for building RAG applications.

Teams use it to connect product catalogs, care guides, and support docs to natural-language search experiences.
