# Getting started with next-intl

`next-intl` makes it straightforward to ship locale-aware routes like `/en` and `/vi` in the App Router.

## Why next-intl?

It handles:

- locale-prefixed routing
- translation messages
- shared navigation helpers for `Link` and `useRouter`

## Example

```ts
import {useTranslations} from 'next-intl';

export function Hero() {
  const t = useTranslations('home.hero');
  return <h1>{t('titleLine1')}</h1>;
}
```

> Keep UI copy in message files, and keep business data language-neutral when possible.

With a clean message structure, the same components can power every locale without duplicated pages.
